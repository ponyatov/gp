# проекция яркостной карты: яркостная подсветки ошибки

- чем больше расходится оригинал с нарисованным, тем ярче будет подсветка ошибки
- пользователь закрашивает яркие области стремять сделать их того же тона что и
  фон, в результате ошибка компенсируется и яркостное выделение исчезает
- яркость нормируется по диапазону минимальной/максимальной ошибки: пользователь
  может выбрать порог срабатывания подсветки, чтобы можно было видеть только
  небольшие области где ошибка максимальна
  - threshold: ниже этого значения ошибки — подсветка = 0 (чёрный). Всё, что
    ниже, не подсвечивается
  - gain: как быстро нарастает яркость от threshold до максимума

сравнение выполняется в не реальном времени, а по команде пользователя:
- камера видит только нарисованное, вклада от проектора нет!
- проектор может использоваться как вспомогательный источник сигнала: сетка,
  угловые метки для калибровки, но карта ошибок в момент сравнения не выводится!
- в кадре камеры нет посторонних предметов (пальцы, инструменты, тени) поэтому
  паразитные элементы не влияют на процесс сравнения
- коррекция внешнего освещения не требуется, так как проектов в момент сравнения
  используется как основной источник освещения рабочего поля
