## Референсные проекты

- Photorealism: Grid Method (by) Dylan Eakin
  - Главное отличие в слоях. Photorealism раскладывает фото на общий тон, тени,
    света и блики, чтобы вы рисовали тон за тоном, а не пытались увидеть всё
    сразу.
  - рисование по сетке, интерфейс для сравнения оригинала/нарисованного с зумом
    до уровня одной ячейки сетки
- Laser Graffiti
  - метод автокалибровки
- Tele-Graffiti
  - рекалибровка при случайных сдвигах проектора/камеры/листа
