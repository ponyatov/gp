# About

Система интерактивного рисования произвольными художественными материалами на
бумаге, стенах, и любых других материалах.

- Проектор
  - проецирует произвольные сетки для ручного переноса изображения
  - проецирует подсвеченные области где нужно нанести текущий выбранный цвет
- веб-камера
  - используется как источник обратной связи для сравнения цифрового оригинала и
    текущей отрисованной вручную области 
- материалы
  - простые карандаши
  - цветные карандаши (в том числе )
  - акриловые краски для нанесения аэрографией
  - цветные мастики для нанесения мастехинами
- использованные алгоритмические методы
  - 4хточечная коррекция
  - цветоделение для произвольных цветов
- ключевые подходы
  - рисование по сетке
  - проекция яркостной карты, чем больше расходится оригинал с нарисованным, тем
    ярче будет подсветка ошибки; пользователь закрашивает яркие области стремять
    сделать их того же тона что и фон, в результате ошибка компенсируется и
    яркостное выделение исчезает
  - использование проектора опционально: для мобильных телефонов достаточно
    работы в режиме визуального сравнения с оригиналом на экране устройства
    (также доступен вариант работы только с камерой и для десктопа)
